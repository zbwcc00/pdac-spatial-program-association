# V7 public reproduction and verification runbook

## Scope

This is the public reproduction record. It reproduces the locked spatial
analysis and later documented sensitivities, reruns the independent GSE202051
program-attribution QC, synchronizes S9/S30-S32 into the v7 supplementary
package, regenerates all five main figures and supplementary Figures S1-S8,
rebuilds the v7 Word manuscript from the versioned Markdown source,
and verifies the content-addressed manifest. It does not
support claims of a cell interaction, TLS morphology, mechanism, causality,
prognosis, or treatment prediction.

The v7 Markdown manuscript is a controlled author-review source document. It
is content-addressed in the manifest and rendered to DOCX by the runbook; it
is not regenerated by an automated scientific-analysis script.

## Environments

The spatial record and the single-cell module used distinct observed
environments. Do not claim that one environment was used for both.

- Spatial historical record: `environment-v6.yml` and `requirements-v2.txt`.
- GSE202051 program-attribution module: `environment-v7-single-cell.yml` and
  `requirements-v7-single-cell.txt`.
- Word rendering: Python with `python-docx==1.2.0`.

## Run order

From the project root, provide a Python executable suitable for the spatial
scripts and one suitable for the single-cell scripts. The full run can take
substantial time because of the four 250-draw graph-null batches and the
8.3-GB decompressed single-cell object.

```powershell
.\REPRODUCE_ALL_V7.ps1 -PythonSpatial <path-to-spatial-python> -PythonSingleCell <path-to-single-cell-python>
```

The script stops on an error. `verification_manifest_v7.json` is created only
after all expected artifacts exist. `release_verification_v7.json` is written
last and must report `PASS` before any external release is prepared.
The supplement synchronizer removes only superseded generated v1/v3 manifest
indexes, so the v7 supplement directory contains a single active package
index. The root v7 manifest hashes every remaining file in that directory.

## Expected checks

- GSE278687 primary patient-level median local correlation: approximately
  `0.4183273`.
- GSE277116 main-18 sample-level median: approximately `0.4136335`.
- Principal array-block null: `0/999`, two-sided add-one `P=0.001`.
- Each 1,000-draw graph sensitivity: `0/1,000`, add-one `P=0.000999`.
- GSE202051 sole designated primary activated-DC versus cDC2 mregDC-like
  comparison: 23 paired patients, median difference approximately `0.479`
  (bootstrap 95% CI `0.424-0.668`), two-sided `P=2.38e-6`.
- Exploratory GSE202051 minimum-cell sensitivities retain 9 paired patients
  at `>=3` cells per label (difference `0.718`, 95% CI `0.359-0.933`,
  FDR q=`0.00641`) and 7 at `>=5` (difference `0.718`, 95% CI
  `0.359-0.747`, FDR q=`0.0169`).
- GSE202051 has no author-defined Tfh label. Its contribution is program
  attribution and non-specificity QC, not spatial validation.
